Детальний опис

Клас CsvExportStrategy реалізує стратегію експорту посилань у формат CSV.

  • Цей клас є частиною патерну "Стратегія" (Strategy) і відповідає за збереження списку об'єктів LinkData у текстовий файл із роздільниками (Comma-Separated Values).

Опис методів компонент

◆ exportData()

bool CsvExportStrategy::exportData ( const QString & filePath,
const std::vector< LinkData > & links ) const
overridevirtual

Експортує переданий список посилань у CSV-файл.

  • Перевизначає віртуальний метод базового інтерфейсу IExportStrategy.
  • Аргументи
    filePathШлях до файлу, у який будуть збережені дані.
    linksВектор об'єктів LinkData, які потрібно експортувати.
    Повертає
    true, якщо експорт пройшов успішно та файл був збережений.
    false, якщо сталася помилка (наприклад, неможливо відкрити файл для запису).
