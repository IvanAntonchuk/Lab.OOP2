Детальний опис

Базовий інтерфейс для всіх стратегій експорту посилань.

  • Цей абстрактний клас є основою патерну "Стратегія" (Strategy). Він визначає загальний контракт (інтерфейс) для різноманітних алгоритмів експорту (наприклад, у CSV або HTML). Завдяки цьому інтерфейсу головний код може викликати експорт, не знаючи конкретної реалізації.

Суто віртуальний метод для експорту даних. Усі похідні класи-стратегії повинні реалізувати цей метод, щоб надати власну логіку збереження посилань у певний формат.

  • Аргументи
    filePathШлях до файлу, у який будуть збережені експортовані дані.
    linksВектор об'єктів LinkData, які потрібно зберегти.
    Повертає
    true, якщо експорт завершився успішно, інакше false.
