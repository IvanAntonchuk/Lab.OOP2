Детальний опис

Клас MainController є Контролером (Controller) у патерні MVC.

  • Він слугує проміжним шаром між графічним інтерфейсом (MainWindow - View) та бізнес-логікою (LinkManager - Model). Контролер приймає дії користувача від View, передає їх у Model для обробки, а потім оновлює View відповідними результатами.
