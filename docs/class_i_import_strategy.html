Детальний опис

Базовий інтерфейс для всіх стратегій імпорту посилань.

  • Цей абстрактний клас є основою патерну "Стратегія" (Strategy) для процесу зчитування даних. Він визначає загальний контракт для різноманітних алгоритмів імпорту (наприклад, із CSV або JSON). Використання інтерфейсу дозволяє легко додавати нові формати імпорту без зміни основного коду програми.

◆ importData()

virtual std::vector< LinkData > IImportStrategy::importData ( const QString & filePath) const
pure virtual

Суто віртуальний метод для імпорту даних із файлу. Усі похідні класи-стратегії повинні реалізувати цей метод, надаючи конкретну логіку парсингу (розбору) файлу відповідного формату.

  • Аргументи
    filePathШлях до файлу, з якого потрібно імпортувати дані.
    Повертає
    Вектор об'єктів LinkData, які були успішно зчитані та розпізнані з файлу.

Реалізує в CsvImportStrategy і JsonImportStrategy.
