Детальний опис

Клас MainWindow є головним вікном програми і виступає Представленням (View) у патерні MVC.

  • Відповідає за відображення графічного інтерфейсу користувача (GUI), прийом вводу (натискання кнопок, введення тексту, перетягування файлів) та делегування обробки цих подій Контролеру (MainController). Не містить бізнес-логіки.
