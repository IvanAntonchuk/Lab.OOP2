Клас DatabaseManager

Клас DatabaseManager відповідає за управління з'єднанням з базою даних SQLite. Детальніше...

#include <databasemanager.h>

Діаграма зв'язків класу DatabaseManager:

Загальнодоступні елементи

bool init (const QString &path)
 Ініціалізує з'єднання з базою даних. Відкриває базу даних за вказаним шляхом та автоматично створює необхідні таблиці, якщо вони ще не існують.
void close ()
 Закриває з'єднання з базою даних. Викликається для безпечного завершення роботи з базою.

Загальнодоступні статичні елементи

static DatabaseManager & instance ()
 Отримує єдиний екземпляр класу DatabaseManager.

Детальний опис

Клас DatabaseManager відповідає за управління з'єднанням з базою даних SQLite.

  • Цей клас реалізує патерн "Одинак" (Singleton), гарантуючи, що в програмі існує лише одне підключення до бази даних у будь-який момент часу.

Опис методів компонент

◆ init()

bool DatabaseManager::init ( const QString & path)

Ініціалізує з'єднання з базою даних. Відкриває базу даних за вказаним шляхом та автоматично створює необхідні таблиці, якщо вони ще не існують.

Аргументи

true, якщо ініціалізація та відкриття бази пройшли успішно, інакше false.
