Детальний опис

Головний клас-менеджер для управління списком посилань.

Відповідає за додавання, видалення, редагування, пошук та фільтрацію посилань, а також управління ієрархією папок та контекстами. У поточній версії архітектури делегує операції постійного зберігання (persistence) класу DatabaseManager, забезпечуючи надійну роботу через SQLite.
