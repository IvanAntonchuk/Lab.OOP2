Детальний опис

Клас WebUtils є допоміжною утилітою для роботи з мережею.

Цей клас забезпечує функціонал для виконання асинхронних HTTP-запитів, використовуючи модуль Qt Network. Його основне завдання — завантаження HTML-коду веб-сторінок і парсинг їх заголовків (<title>) у фоновому режимі, що гарантує відсутність блокування головного потоку графічного інтерфейсу (UI).

Опис методів компонент

◆ fetchTitleAsync()

void WebUtils::fetchTitleAsync ( const QString & url)

Асинхронно отримує заголовок (<title>) веб-сторінки за URL.

  • Функція ініціює HTTP GET запит. Оскільки запит асинхронний, метод завершується миттєво. Після успішного завантаження сторінки або виникнення мережевої помилки клас генерує сигнал titleReady().
  • Аргументи
    urlРядок із повною URL-адресою веб-сторінки (наприклад, "https://google.com").

◆ titleReady

void WebUtils::titleReady ( const QString & url,
const QString & title )
signal

Сигнал, що випромінюється після завершення мережевого запиту. Цей сигнал можна підключити до слота в UI (наприклад, у AddLinkDialog), щоб автоматично заповнити поле назви посилання.

  • Аргументи
    urlОригінальний URL, на який відправлявся запит.
    titleЗнайдений заголовок сторінки (якщо заголовок відсутній або сталася помилка — повертається сам URL).
